# 04 — Sửa UI gameplay

Lỗi chính bản trước:

- Nhãn cột lệch vì thiếu ô trống trùng số làn
- Token hình vuông cao, tràn ô, không đọc được HP/ATK
- Triển khai: mỗi unit 5 nút làn, đẩy bàn cờ khỏi màn hình
- Army builder nhân đôi 24 unit, nút Start mất hút dưới đáy
- Ô bàn không bấm được; Hủy targeting thiếu; Discard không tắt sau khi dùng

Cách chơi mới:

1. Chọn đơn vị trữ quân
2. Bấm ô Support trống trên bàn
3. Xong triển khai → chơi bài trên tay → Giao chiến
